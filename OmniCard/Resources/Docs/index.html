Welcome to OmniCard

OmniCard is a Windows desktop app for scanning and managing trading card collections. It identifies physical cards — scanned with a TWAIN scanner or your phone's camera — using perceptual image hashing and OCR, then tracks them across storage locations, sealed-product inventory, and sales & fulfillment (including listing on eBay).

Supported games: Magic: The Gathering, Pokémon, One Piece TCG, Yu-Gi-Oh!, Final Fantasy TCG, and Riftbound.

New here? Read The Main Window and The Game Selector below, then jump to Scanning Cards to add your first cards, or Import & Export if you already have a CSV.

The Main Window

Everything lives in one window with three regions:

  • Menu bar (top) — File, Edit, View, Collection, Selection, Scanner, Tools, and Help. Every command is reachable here.
  • Toolbar — the Game selector and quick actions.
  • Sidebar navigation (left, collapsible) — switches between the five main tabs: Dashboard, Collection, Scanner, Sales, and Lists.
  • Status bar (bottom) — app version, current status message, price-update progress, a diagnostics count, and eBay connection state.

The Game Selector

The Game dropdown in the toolbar scopes the entire app to one game at a time — the Collection grid, Dashboard stats, scanning, and set lists all follow it. Switching games swaps the underlying database (each game has its own), so changing it is instant and non-destructive.

Sealed-product inventory, orders, customers, and sales are game-agnostic and shared across all games — only card browsing and scanning are game-scoped.

Holdings tables

Four breakdown tables — by Game, by Category, and by Location (each showing Units, Cost, Market, Unrealized, and a share bar), plus Realized P&L by Game (Sold count, Proceeds, Cost, Profit).

  • Total Cards / Sets / Foils / Total Value — headline counts for the selected game.
  • Rarity breakdown — Common, Uncommon, Rare, Mythic, Other.
  • Sets in Collection — a tile per set showing the set symbol, owned / total (percent complete), and total physical copies. Click a set to expand it.
"No holdings yet…" appears until you own something. Prices come from the latest catalog download — run a price refresh if values look stale.

Collection

Browse and manage what you own. A Cards / Inventory toggle switches between two modes:

Cards mode

  • A grid or list of owned cards for the selected game, with search, sort, and filter.
  • Type-ahead jump — start typing a card's name to scroll straight to it (Explorer-style); repeat the same letters to cycle through matches.
  • Locations — drill into a storage location to see just the cards stored there.
  • Double-click a card to open its detail/editor. Right-click for per-card actions (move, tag, list for sale, trade…).

Inventory mode

Swaps the grid for sealed-product inventory — see Sealed Inventory.

Use Collection ▸ Sort & Filter Builder to build reusable sort/filter rules, and the Set Filter to narrow to specific sets.

Scanner

The live scanning workflow. Enabled once a scanner (TWAIN) or phone camera source is connected.

  1. Scan a card — it appears in the scan queue with the best match(es).
  2. Review the match; adjust condition, foil, quantity, and tags as needed.
  3. Correct the match if it's wrong (this trains future matches — see Corrections).
  4. Commit the queue to add the cards to your collection.

See Scanning Cards for the full workflow and How Matching Works.

Sales

The selling hub, organised into sub-tabs:

  • Pick List — cards you need to pull for open orders.
  • Listings — everything currently listed for sale (locally and on eBay).
  • Orders — the order pipeline as a drag-and-drop kanban board.
  • Customers — your customer records.

Details in the Sales & Fulfillment chapter.

Lists

Custom card lists and decklists. The master list is on the left, its contents on the right. Lists feed the Decklist Check tool and can be turned into a storage location via Move List to Location. Create lists manually, from an import, or from scanned cards (Scanner ▸ Create List from Scans).

Scanning Cards

  1. Connect a source. Scanner ▸ Connect to Scanner… for a TWAIN scanner, or use the phone-camera flow via the web companion.
  2. Pick the game in the toolbar so matches are looked up in the right catalog.
  3. Scan. Each card is hashed and matched; results land in the scan queue with a confidence indicator.
  4. Review & edit condition, foil, quantity, tags. First copies you own can show a star badge, and a price-tier accent (configurable in Settings ▸ Display).
  5. Commit to write the cards into your collection (optionally keeping the scan images — Settings ▸ Scan Workflow).
You can turn a batch of scans into a List (Scanner ▸ Create List from Scans) or link a scan to a trade (right-click ▸ Link to Trade) before committing.

How Matching Works

OmniCard combines several signals into one confidence score:

  • Perceptual hash (pHash) — a fingerprint of the card art that survives resizing and minor blur.
  • Foil edge hash — a color-robust hash used for foils, whose color shift otherwise breaks plain pHash.
  • OCR — reads text such as collector numbers / set codes to disambiguate look-alikes and reprints.

The higher the combined score, the more confident the match. Low-confidence scans are flagged so you can correct them.

Corrections & Training

When you fix a wrong match, OmniCard records the correction per game against that card's image hash. The next time a card with the same fingerprint is scanned, the correction boosts the right match — so accuracy improves as you use it.

Storage Locations

Locations (a.k.a. storage containers) are where your cards physically live — boxes, binders, deck boxes, shelves. Manage them via Manage Storage Locations. Each card can be assigned to a location, and the Dashboard's Holdings by Location reflects value per location.

Move cards with Move to Location (single/selection) or Move List to Location (a whole list).

Binders

Binder locations get a visual page-slot editor: drag and drop cards into pages and slots, view facing-page spreads, and page through with the bottom pagination strip (First / Prev / spread list / Next / Last). Open it from a binder location, or add a card straight into a specific page/slot.

Moving Cards

Move to Location relocates the selected card(s). Move List to Location relocates every card in a list at once — handy for filing a freshly-built deck or a purchase into a box. Every move is recorded in Movement History.

Price Sheets

Create Price Sheet… on a location exports a printable PDF of the cards in that location with prices — useful for shows, trade nights, or a physical binder insert.

Location Audit

The Audit Report verifies a location's expected contents against what's physically there and exports a PDF. Use it to reconcile a box after a busy day of scanning and selling.

Sealed Product Inventory

Beyond singles, OmniCard tracks sealed product (booster boxes, packs, bundles) with proper cost-basis accounting. Open it via the Inventory toggle inside the Collection tab.

  • Products — the sealed items you stock. Add/edit via the product editor.
  • Lots — each purchase is a lot with a quantity, unit cost, source, and date, so cost basis stays accurate as prices change.
  • Open Units — record opening/consuming sealed units (e.g. cracking a box for singles).

Listing Cards for Sale

Right-click a card (or use Selection ▸ List for Sale) to create a listing at a suggested price. Listings appear on the Sales ▸ Listings tab. To list on eBay specifically, use the eBay Listing editor (requires a connected eBay account — see Connecting eBay).

Orders (Kanban)

The Sales ▸ Orders tab is a drag-and-drop kanban board. Cards move through columns as you fulfill them (Created → picking → shipped → Completed). Drag an order card between columns to change its state; open a card for full details.

  • Pick List tells you which cards to pull for open orders and where they're stored.
  • Completed orders can be edited with a required reason and a full field-diff audit trail; the ledger and inventory auto-correct.

Receipts

Receipts print for fulfilled orders. Configure width, margins, font size, whether prices show, footer text, and default printer in Settings ▸ Sales & Receipts. Identical line items are condensed automatically.

Customers

The Sales ▸ Customers tab holds customer records that orders link to. eBay orders import their buyer details automatically.

Trades

Trade a card away and OmniCard records a note and photo, removes it from valuation, and logs the movement. You can start a trade from the web companion's Trade button or link a scan to a trade in the desktop app; committing the trade deletes the traded-away card and records it in the permanent trades log.

Connecting an eBay Account

Do this once to sell on eBay from OmniCard.

  1. Open Tools ▸ Connect to eBay….
  2. An eBay sign-in window opens (an embedded browser). Sign in to your eBay account and grant OmniCard permission.
  3. On success the window closes and the status bar shows eBay: Connected. Your tokens are stored securely and refreshed automatically.
To disconnect later, use Tools ▸ Disconnect from eBay.

eBay Selling Details

Before your first listing, fill in Settings ▸ eBay Selling:

  • Ship-from address — location name, address, city, state, postal code, ISO-2 country, phone.
  • Shipping — free-shipping toggle, shipping cost, handling-time (days), shipping-service code.
  • Returns — whether you accept returns, the return window (days), and who pays return shipping.

Running eBay Setup

Click Run eBay Setup in Settings ▸ eBay Selling. This one-time step provisions your eBay seller account so listings can be created:

  1. Opts your account into eBay Business Policies.
  2. Ensures an inventory location exists.
  3. Creates (or reuses) your fulfillment (shipping), payment, and return policies.

A live status log shows each step. Once it completes, you can list cards on eBay.

Listing & Syncing on eBay

Use Selection ▸ List on eBay or the eBay Listing editor to publish a card. Card condition (NM / LP / MP / HP) maps to eBay's condition and a "Card Condition" grade. OmniCard syncs listing and order state from eBay so sold items flow into your Orders pipeline and buyer details create/attach a Customer.

Settings — Display

Open Settings from Edit ▸ Settings. The Display section controls:

  • Card-detail font size, card-preview size, scanner font size.
  • Scan-tile price indicators — the non-bulk price threshold (green accent) and the high-value price threshold (blue accent).

Settings — Data Location

Shows the current data folder and lets you Browse to a new one and Migrate your data store there (with a cancel option). All game databases, scans, and logs live under this folder.

Default location: %LOCALAPPDATA%\OmniCard.

Settings — Sales & Receipts

  • For-Sale location — where picked cards are moved during fulfillment.
  • Company Profile — name, address, city/state/postal/country, email, phone, and a logo for receipts.
  • Receipt setup — width (mm), margin (mm), font (pt), show prices, footer text, and default printer.

Settings — eBay Selling

The ship-from address, shipping, and returns configuration plus the Run eBay Setup button. Covered under eBay Selling Details and Running eBay Setup.

Settings — Scan Workflow

  • Store vs discard scan images after committing a scan.
  • Scan Archives — import a previously archived scans .zip and relink it to inventory.

Importing

File ▸ Import… (Ctrl+I) is a hub that auto-detects what you give it:

  • CSV collection exports — mapped and previewed before import.
  • Decklists — plain-text lists, batch-imported with a master/detail preview.
  • Add files… or Add URL(s)… — import from Moxfield / Archidekt links.

After import the collection refreshes automatically.

Exporting

The File ▸ Export submenu exports your collection (e.g. to CSV) for backup or use in other tools.

TCGplayer Order Import

Import TCGplayer orders (Shipping Export) to create orders in the pipeline. This brings in orders only — not card line items — so you fulfill against your own inventory.

Check Decklist

Tools ▸ Check Decklist… compares a decklist against what you own so you can see what you're missing. A batch variant checks several lists at once.

Movement History

Tools ▸ Movement History… is the audit log of every card move — location changes, sales, trades — with timestamps.

Log Viewer

Tools ▸ View Logs… parses the app's logs with level/time/text filters and a "copy for AI" action, so you can hand diagnostics to support (or an assistant) when troubleshooting.

Top 100 Cards

Collection ▸ Top 100 Cards lists your highest-value unlisted singles across all games, with a "go to location" jump so you can pull them quickly.

Tags

Tag individual card lots and search them with tag: queries. Add tags while scanning or in the card editor, bulk-add to a selection, and manage the tag library (rename / delete / merge, with usage counts) via Manage Tags. Tags also display in the web companion.

Web Companion

OmniCard ships a read-only web app that browses the same collection and lets you scan with a phone from any device on the network. It opens the desktop app's databases read-only. Features include browsing the collection, a flip-through binder view (swipe + page-turn + tap-to-preview), and a Trade workflow that hands trades back to the desktop app.

The web companion is launched separately, pointed at the desktop app's data folder. It never writes to your databases directly — trades and scans are handed back to the desktop app to apply.

FAQ & Troubleshooting

My prices look out of date.

Prices come from the latest catalog download. Let a price refresh finish (watch the status bar), then Refresh the Dashboard.

A scan matched the wrong card.

Correct it in the scan queue before committing — OmniCard learns the correction for next time. See Corrections.

The Scanner tab is greyed out.

Connect a source first via Scanner ▸ Connect to Scanner…, or scan from your phone through the web companion.

eBay listing fails.

Make sure you've connected eBay (Connecting eBay), filled in Selling Details, and run eBay Setup successfully.

Where is my data stored?

%LOCALAPPDATA%\OmniCard by default; change it under Settings ▸ Data Location.

# Getting support

OmniCard is free software and will stay that way. Every feature is available to everyone under the MIT License. The free version comes as-is, with no support. If you need help setting it up or keeping it running, you can buy paid support from the author.

## Free use

You don't have to pay for anything to use OmniCard. The free version includes no support:

- You can report bugs on the [Issues](https://github.com/anubisascends/OmniCard/issues) page on GitHub, but nobody is obliged to reply or to fix them by any date.
- For common problems, start with [Troubleshooting](help:troubleshooting).

## Paid support

If you need more than that, you can buy paid support from the author. It can include:

- **Custom setup.** Installing and configuring OmniCard for your environment: hosting on IIS or as a Windows service, SQL Server, moving your existing data in, connecting eBay, and so on.
- **Priority technical support.** Direct help with problems running or using OmniCard, with priority response.
- **Bug fix priority.** Bugs that affect you go to the front of the queue.

The price depends on what you need and is agreed with you when you buy.

To ask about paid support, contact [@anubisascends](https://github.com/anubisascends) on GitHub.

> [!NOTE]
> Paid support is a service. It doesn't change the license, and you don't need it to use OmniCard.

## Fixes are always public

Paying moves your bug up the queue. The fix itself goes into the public release for everyone, never into a private build. Custom development works the same way: the author only takes on changes that help the whole community, and turns down work that would only serve one customer.

As the author puts it: *the user, free or paid, owns the problem; the developer owns the solution.*
